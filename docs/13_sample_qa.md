# 一、异常聚集 `massing`

**样例场景**：MAR20 卫星遥感图，某军用机场停机坪，9 架军机。

```json
FACTS = {
  "view": "satellite", "image_size": [1280, 960],
  "objects_summary": {"military-plane": 9},
  "objects": [{"cls":"military-plane","box_1000":[398,175,447,232],"position":"画面上中方","model":"A3"}, ...],
  "events": [{"type":"massing","subtype":"equipment","object_count":9,
              "region_box_1000":[312,168,704,395]}]
}
```

## 主线三轮

```
轮1  Q: <image>这张画面中是否存在异常？是什么类型的异常？
     A: 存在异常，为装备集结。

轮2  Q: 该异常出现在画面的什么位置？
     A: 集结区域位于 [312,168,704,395]，处在画面上部偏中，约占画幅的六分之一。

轮3  Q: 这些目标是怎么排列的？                        ← 抽到 formation 侧面
     A: 九架飞机排成两列，前列五架、后列四架，机头统一朝向西南方，
        列内间距基本一致，后列相对前列略有错位，整体呈规则阵列。
```

## 各侧面单轮样例

### `evidence` 判定依据　`must-not: 位于 画面 方位 左侧 右侧 上方 下方`
```
Q: <image>凭哪些迹象判断这是装备集结？
A: 三点依据：一是目标为军用固定翼飞机，非民用航空器；二是数量达九架，
   超出常态停放规模；三是呈规则列队、间距均匀、机头朝向一致，
   属于集中部署形态而非零散停放。
```

### `position` 空间方位　`must-not: 颜色 形态 数量 因为 依据`
```
Q: <image>集结区域在画面的什么位置？
A: 在画面上部偏中，横向大致处在从左往右四分之一到七成之间，
   纵向靠近上缘往下五分之一处，区域范围 [312,168,704,395]，
   下方三分之二的画幅是空置地面。
```

### `formation` 排列形态　`must-not: 颜色 烟 火`
```
Q: <image>这批目标呈现什么样的排列形态？
A: 排成两列纵队，前列五架、后列四架，机头一致朝向同一方向，
   列内间距均匀，两列之间留有一个机身宽度的通道，整体阵列规整。
```

### `composition` 目标构成　`must-not: 位于 画面 方位`
```
Q: <image>集结区域内都是些什么目标？
A: 全部为军用固定翼飞机，共九架，未见运输车辆、地勤设备或人员，
   也没有混入民用航空器，目标类型单一。
```

### `scale` 规模量化　`must-not: 颜色 朝向`
```
Q: <image>这次集结的规模有多大？
A: 共九个目标，聚集区域约占整幅画面的六分之一，目标之间平均间距
   小于一个机身长度，属于中等规模的密集停放。
```

### `site` 场地环境　`must-not: 数量 排列`
```
Q: <image>这些目标处在什么样的场地上？
A: 位于硬化铺装的停机坪区域，地面平整呈浅灰色，边缘可见滑行道标线，
   坪区外侧是成片的空置地面，未见建筑或掩体设施。
```

### `full` 综合（占 10%）
```
Q: <image>请综合描述这张画面中的异常情况。
A: 卫星遥感画面，画面上部偏中的停机坪上停放九架军用飞机，占据
   [312,168,704,395] 区域。九架分两列排布，机头朝向一致，间距均匀。
   该密集列队形态符合装备集结特征，建议持续观察。
```

# 二、爆炸/火光 `explosion`

**样例场景**：FASDD_UAV 无人机航拍，林地中一处明火伴生烟雾。

```json
FACTS = {
  "view": "uav", "image_size": [1024, 1024],
  "objects_summary": {"fire": 1, "smoke": 1},
  "objects": [{"cls":"fire","box_1000":[421,388,533,502]},
              {"cls":"smoke","box_1000":[380,240,590,420]}],
  "events": [{"type":"explosion","src_label":"fire"}, {"type":"smoke"}]
}
```

## 主线三轮
```
轮1  Q: <image>画面中是否存在异常？属于哪一类？
     A: 存在异常，为火光，并伴有烟雾。

轮2  Q: 火光出现在画面的哪个位置？
     A: 火点位于 [421,388,533,502]，在画面中部略偏下。

轮3  Q: 这处火光的亮度和形态有什么特点？              ← 抽到 intensity 侧面
     A: 火焰呈明亮橙红色，核心区域接近白色，与四周深绿色植被形成强烈反差，
        火头轮廓不规则并向上方拉长，边缘有跳动的碎焰。
```

## 各侧面单轮样例

### `evidence` 判定依据　`must-not: 位于 画面 方位 左侧 右侧`
```
Q: <image>判定为火光异常的依据是什么？
A: 依据有三：存在高亮度橙红色区域，与周边地表亮度反差显著；
   该区域上方伴生灰褐色烟柱，符合燃烧产物特征；火区边缘呈不规则跳动形态，
   区别于反光或人造光源。无法从单帧判断起火原因。
```

### `position` 空间方位　`must-not: 颜色 亮度 形态 数量`
```
Q: <image>火点在画面的什么位置？
A: 在画面中部略偏下，横向约在从左往右四成到五成之间，纵向大致居中偏下，
   范围 [421,388,533,502]，距画面下缘还有约一半的距离。
```

### `intensity` 亮度形态　`must-not: 位于 画面 方位 数量`
```
Q: <image>描述这处火光的亮度特征。
A: 火焰整体呈明亮橙红色，核心部位亮度最高、接近白色，向外依次过渡为
   橙色与暗红色，与周边深色地表形成强反差，是全图最亮的区域。
```

### `debris` 伴生现象　`must-not: 位于 方位`
```
Q: <image>火点周围有什么伴生现象？
A: 火区正上方涌起灰褐色烟柱，浓度较高并向斜上方扩散；火区外沿的地表
   颜色发暗，呈现灼烧后的痕迹；未观察到明显的碎片飞散。
```

### `extent` 波及范围　`must-not: 颜色 亮度`
```
Q: <image>这处火情波及范围有多大？
A: 明火区域约占整幅画面的百分之一，加上外围灼痕与烟雾覆盖，
   受影响范围扩大到约画面的五分之一。周边未见建筑、车辆或人员，
   最近的可辨识地物是画面右下的一条小径。
```

### `stage` 燃烧阶段　`must-not: 位于 方位`
```
Q: <image>火势处于什么阶段？
A: 明火范围集中且火焰亮度高、烟柱浓密上涌，符合旺盛燃烧阶段的特征。
   但仅凭单帧画面无法判断火势是在扩大还是已经受控。
```

### `full` 综合（占 10%）
```
Q: <image>综合描述画面中的火情。
A: 无人机航拍画面，画面中部略偏下有一处明火，位于 [421,388,533,502]，
   火焰明亮呈橙红色。其上方 [380,240,590,420] 区域为灰褐色烟雾，
   向斜上方扩散。周边为植被覆盖地表，未见人员与建筑。
```

# 三、烟雾 `smoke`

**样例场景**：FASDD_UAV，只有烟无明火。

```json
FACTS = {"view":"uav","image_size":[1024,768],
  "objects_summary":{"smoke":1},
  "objects":[{"cls":"smoke","box_1000":[102,64,388,301]}],
  "events":[{"type":"smoke"}]}
```

## 主线三轮
```
轮1  Q: <image>这张画面里有没有异常？是什么？
     A: 有异常，为烟雾。

轮2  Q: 烟雾在画面的什么位置？
     A: 烟雾区域位于 [102,64,388,301]，在画面左上方。

轮3  Q: 这团烟雾是什么颜色的？                        ← 抽到 color 侧面
     A: 呈灰白色，靠近底部略偏灰暗，越往上越淡并逐渐透出背景，
        整体色调偏冷，未见黑褐或黄色成分。
```

## 各侧面单轮样例

### `evidence` 判定依据　`must-not: 位于 画面 方位 左侧 右侧`
```
Q: <image>为什么判断画面中存在烟雾？
A: 存在一片边界模糊、半透明的灰白色区域，形态呈自下而上的柱状扩散，
   下窄上宽，遮挡了其后方的地表纹理，符合烟羽的视觉特征，
   区别于云层与地面雾气。
```

### `position` 空间方位　`must-not: 颜色 浓密 形态 数量`
```
Q: <image>烟雾出现在画面的哪一块？
A: 在画面左上方，横向占据从左缘往右约四成的范围，纵向从上缘一直延伸到
   画面中部偏上，区域为 [102,64,388,301]，紧贴画面左上角。
```

### `morphology` 烟柱形态　`must-not: 位于 方位 火 爆炸`
```
Q: <image>这团烟雾是什么形态？
A: 呈柱状自下而上升起，底部收窄、顶部散开成扇形，边缘模糊没有明确轮廓；
   下半段较为密实，上半段稀薄并出现断续的絮状分支。
```

### `color` 颜色　`must-not: 位于 方位 数量`
```
Q: <image>烟雾呈现什么颜色？
A: 整体灰白色，根部颜色略深偏灰，向上逐渐变淡直至半透明，
   未见黑褐色或黄色成分，色调偏冷。
```

### `drift` 扩散走向　`must-not: 颜色 浓密`
```
Q: <image>烟雾往哪个方向扩散？
A: 主体自下方向上升起后明显向右偏斜，扩散方向为东北，
   顶部散开的幅度约为根部的三倍，说明存在侧向气流。
```

### `occlusion` 遮蔽程度　`must-not: 颜色 形态`
```
Q: <image>烟雾对地面观察造成多大影响？
A: 遮挡了画面左上约六分之一区域的地表，被遮部分的地物轮廓已不可辨认；
   遮蔽区边缘还有约同等面积的半透明过渡带，其下的地表仍可勉强分辨。
```

### `full` 综合（占 10%）
```
Q: <image>综合描述这张画面。
A: 无人机航拍画面，左上方 [102,64,388,301] 区域存在一团灰白色烟雾，
   呈柱状升起并向东北方向偏斜扩散，遮挡了其下方的地表。
   画面其余部分为林地，未见明火与人员活动。
```

# 四、越界移动 `border_crossing`

**样例场景**：VisDrone-MOT 三帧序列，4 辆车中 3 辆越过虚拟边界。

```json
FACTS = {"view":"uav","image_size":[960,540],"frames":3,
  "objects_summary":{"vehicle":4},
  "events":[{"type":"border_crossing","boundary":"restricted_A",
             "direction":"由界外进入禁区","crossed_count":3,
             "boxes_last_frame":[[214,388,266,436],[402,371,455,419],[578,392,631,441]]}]}
```

## 主线三轮
```
轮1  Q: <image><image><image>这三帧按时间顺序拍摄，画面中是否发生异常？是什么？
     A: 发生异常，为越界移动。

轮2  Q: 越界目标在最后一帧中的位置是？
     A: 三个越界目标分别位于 [214,388,266,436]、[402,371,455,419]、
        [578,392,631,441]。

轮3  Q: 这些目标是怎么移动的？                        ← 抽到 trajectory 侧面
     A: 三个目标从画面下方持续向上方移动，三帧之间位移基本均匀，
        方向一致向北，中途没有停顿或折返，第四个目标则始终停在原处。
```

## 各侧面单轮样例

### `evidence` 判定依据　`must-not: 位于 画面 方位 左侧 右侧`
```
Q: <image><image><image>判定发生越界的依据是什么？
A: 依据是目标轨迹与禁区边界线的相交关系：三个车辆在首帧处于边界外侧，
   末帧处于内侧，运动方向持续同向，三帧总位移超过画面对角线的百分之二，
   可排除定位抖动造成的误判。
```

### `position` 空间方位　`must-not: 颜色 方向 数量 依据`
```
Q: <image><image><image>越界目标现在处在画面的什么位置？
A: 三个目标横向分散在画面左侧三成、中部与右侧六成处，纵向都集中在
   画面中下部约四成高度的位置，彼此大致处于同一水平线上。
```

### `trajectory` 运动轨迹　`must-not: 颜色 数量 烟`
```
Q: <image><image><image>描述这些目标的运动过程。
A: 从画面下缘附近起步，沿近乎垂直的路线持续向上推进，三帧之间的位移量
   基本相等，说明速度稳定；运动方向自始至终朝向北方，没有转向或停顿。
```

### `timing` 跨越时机　`must-not: 颜色 外观`
```
Q: <image><image><image>它们是在什么时候越过边界的？
A: 第一帧时三个目标都还在边界外侧，第二帧已经贴近边界线，
   在第二帧到第三帧之间完成跨越，第三帧时全部处于边界内侧。
```

### `boundary_relation` 边界关系　`must-not: 颜色 外观`
```
Q: <image><image><image>这些目标与禁区边界是什么关系？
A: 三个目标当前均位于禁区内侧，距边界线约为其自身车长的两到三倍；
   跨越方向是由界外进入禁区。第四个目标始终停留在界外，未构成越界。
```

### `group` 群体特征　`must-not: 颜色 位于`
```
Q: <image><image><image>这些越界目标是单独行动还是成组的？
A: 三个目标同步移动、速度接近、始终保持大致相同的横向间距与同一推进节奏，
   表现为一次成组行动而非各自独立通过。
```

### `full` 综合（占 10%）
```
Q: <image><image><image>综合描述这三帧序列中的情况。
A: 三帧无人机航拍序列。画面中共四个车辆目标，其中三个自下而上持续移动，
   在第二至第三帧之间越过禁区边界线，当前位于界内，
   分别处于 [214,388,266,436]、[402,371,455,419]、[578,392,631,441]。
   第四个目标全程静止于界外。
```

# 五、正常 `normal`（含困难负样本）

**样例场景**：DOTA 卫星图，民用停车场 14 辆车密集停放 —— 规模达标但不含军事目标。

```json
FACTS = {"view":"satellite","image_size":[1024,1024],
  "objects_summary":{"vehicle":14},
  "events":[],
  "hard_negative": true,
  "hard_negative_reason":["massing/equipment: 14 个目标密集成簇但不含军事目标"]}
```

### `hard_neg` 困难负样本辨析（8,000 条，最重要）
```
Q: <image>画面中这些密集停放的车辆是否构成装备集结？
A: 不构成。虽然十四个车辆目标确实密集成簇、达到了集结的规模条件，
   但从车体尺寸与轮廓判断均为民用车辆，未见坦克、装甲车或军用运输车，
   排列也是停车场式的规整分格停放而非战术布设，因此判定为正常停车场景。
```

### `scan` 常态巡查
```
Q: <image>这张画面里有什么？是否需要上报？
A: 画面为一处硬化地面的停车区域，内有十四辆民用车辆规则停放，
   周边是道路与低矮建筑。未见军事装备、烟火迹象或人员聚集，
   态势正常，不需要上报。
```

### `position` 主要目标方位
```
Q: <image>画面中的车辆主要分布在哪里？
A: 集中在画面中部偏左的区域，横向约占从左往右两成到六成的范围，
   纵向处在中间三分之一处，其余部分为空置路面与建筑顶部。
```

### `full` 综合
```
Q: <image>综合描述这张画面。
A: 卫星遥感画面，画面中部偏左为一处停车场，内有十四辆民用车辆分两排停放，
   排列规整。周边可见道路与建筑。画面中未见军事装备、烟火或人员聚集，
   属于正常场景。
```

# 六、其余三类任务样例

# 七、请重点看这几处

1. **四类异常的描述读起来是不是真的不一样**？聚集在讲"几列几排"，爆炸在讲"亮度层次"，
   烟雾在讲"形态走向"，越界在讲"帧间位移"。如果你觉得哪两类还是像，说明侧面设计要调。

2. **`must-not` 够不够狠**？比如 `position` 侧面禁了"颜色"，`color` 侧面禁了"位于/方位"。
   有没有哪条禁得过头，导致答案写不出来？

3. **答案长度**。现在大多是 2–3 句、40–60 字。要不要更长（更细但更容易编）
   或更短（更稳但信息量少）？

4. **口吻**。现在是情报分析式的书面语。要不要更口语一点，或者更格式化一点？

5. **不确定的表述**。爆炸类的 `stage` 侧面里刻意写了"仅凭单帧无法判断火势是在扩大还是
   已经受控"。这类"说不知道"的表述要保留多少比例？
