# 数据获取与合成策略评估

> 针对「异常类型体系」里填不上的格子，评估四类数据方案。
> **判断依据是这一轮踩出来的教训，不是可行性想象。**

---

## 零、先立一条判据

所有方案都用同一把尺子量：

> **它产出的标签，是「数据自带的事实」，还是「我们推断出来的语义」？**

这一轮六个异常类死了四个，**死的全是推断出来的**（几何规则从 bbox 推高层语义），
活的两个都是**数据集自带的真标注**（FASDD 的 fire/smoke）。

第二把尺子：

> **它能不能提供「过程」？**

行为族（集结/机动/越界/侦察/伪装/构筑/协同/补给）**全部需要过程**。
单帧只能给一个瞬间构型 —— 一排停着的车和一支停下来的车队，像素上没有区别。

---

## 一、民用数据"近义词"替换（数据借调）

### 判断：**部分采纳，但不能用它训"异常判定"**

这个方案我们**实际上已经跑过了，而且失败了** —— 这是本轮最贵的一课。

原始设想是：「车和坦克在卫星图上都是高密度聚集的矩形 box，算法学会的是密度与
空间分布异常，而不是装备本身」。听上去成立，实测不成立：

| 实测 | 结果 |
|---|---|
| 40 辆随机散车能凑出的"最整齐队列" | 间距变异系数 **0.077** |
| 带抖动的真车队 | 间距变异系数 **0.156** ← **随机的比真的还整齐** |
| 80 辆以上密集场景，随机线的间距 | **0.8 车长**，比任何真车队都紧 |
| DroneCrowd 人群（标注 99–169 人）让模型自由描述 | **11/15 说"零散分布""非密集聚集"** |

**根因**：停车场的一排车，本身就是「共线 + 等距 + 细长」；广场上的人流，本身就是
「高密度聚集」。**它们不是"像"集结，它们在几何上就是集结的定义。**
拿它们训"集结检测"，等于教模型看见任何停车场、任何广场都报警。

### 但有一个版本是成立的，而且很值钱

**借调民用数据去训「感知能力」，而不是「异常判定」：**

| 能力 | 民用数据能不能训 | 为什么 |
|---|---|---|
| 密集目标计数 | ✅ 能 | 数车就是数车，和是不是坦克无关 |
| 空间分布描述 | ✅ 能 | 「集中在画面右下」是客观描述 |
| 密集区域定位 | ✅ 能 | 同上 |
| 目标类别识别 | ✅ 能 | |
| **「这是不是异常」** | ❌ **不能** | 民用场景**本身不是异常**，标成异常就是编 |

**所以民用密集场景的正确用法是两个**：
1. **`concentration`（密集分布）的正样本** —— 这是征候族的客观标签，不是异常判定
2. **`massing`（集结）的困难负样本** —— 「人/车很多但这是日常，不是集结」

我们已经这么做了：DroneCrowd 3176 + VisDrone 4045 转成困难负样本，
配套文案「未见异常。画面里确实有 N 人，数量不少，但这是广场、道路一类公共场所的
日常人流，分布松散，不构成异常聚集。」

### 轨迹数据（ADS-B / AIS）—— 另说，但这是另一个任务

民航绕飞、货轮避风的异常轨迹**确实是真异常，标签也是真的**。但：

- 它是**时序表格数据**，不是影像。做出来是轨迹异常检测模型，不是 VQA
- 要接进本项目，得先把轨迹渲染成图，而**渲染图上的"异常"是我们画上去的**，
  又回到"推断语义"那条死路
- **建议：单独立项**，别混进影像 VQA

## 二、开源遥感数据集

### 判断：**采纳，但只填征候族和目标识别，不要拼图造异常**

| 数据集 | 判断 | 理由 |
|---|---|---|
| **DOTA** | ✅ 已在用 | 3181 切片。车/船/储罐/桥的真框。**无军事目标**，当目标识别与困难负样本 |
| **SpaceNet** | ✅ 值得接 | 建筑/道路提取，**有多时相子集** → 直接填 `infra_change`（设施变化），这是我们完全空白的一格 |
| **MSTAR** | ⚠️ 谨慎 | 见下 |

### ⚠️ 「把几张图拼在一起，人工制造异常集结」—— 不建议

这条我要明确反对。理由不是技术难度，是**它会污染描述任务**：

- 本项目 60% 是**描述题**，模型要说清画面里有什么、什么样、在哪
- 拼接图的光照、阴影方向、地面纹理、分辨率会对不上，**模型学到的是"找拼接缝"**
- 更糟：拼出来的场景在物理上可能荒谬（坦克停在水面上、飞机摆在民房屋顶），
  而我们会煞有介事地给它配一段「装备集结」的描述 —— 这正是「编」

如果只做**检测**（画框），copy-paste 增强是成熟做法；
但做**描述与解释**，拼接图是负资产。

### MSTAR 的问题：**模态不对，粒度也不对**

- **模态**：SAR 图像，而我们的底座 Qwen-VL 是光学训练的。混进去要么学不到，
  要么污染光学表征。**要做 SAR 得是独立的数据集条目和独立的评估**
- **粒度**：MSTAR 是 128×128 的单车辆切片，**不是场景**。
  我们的任务是场景级判读（这一片有什么、什么关系），单目标切片填不了

**结论**：除非明确要做 SAR 能力，否则不接。

## 三、AIGC 样本扩充

### 判断：**只采纳"域增强"，坚决不采纳"造内容"**

这里必须把两件事分开，它们的风险差一个量级：

#### ✅ 域增强（Domain Augmentation）—— 有限采纳

**做法**：拿一张**已有真实标注**的图，用 ControlNet 固定布局，只改天气/光照/季节。

**为什么可以**：布局不变 → **框仍然有效，数量仍然准确**。标签没有变成猜的。

**为什么"有限"**：同一个场景生成 N 份，是**同质化**。你在这个项目最早就提过
「反同质化」的要求。建议：
- 只对**稀缺类**做，且**每张最多 2–3 个变体**
- 变体之间必须是**真正不同的域**（雪地 / 夜间 / 沙尘），不是同一天气的随机重采
- 元数据里标 `synthetic: true` + `source_image_id`，**切 train/test 时必须同组**
  （否则原图在训练集、变体在测试集，指标虚高）

#### ❌ 造内容 —— 不采纳

**做法**：让扩散模型生成「中东某基地」这样的新场景。

**为什么不行**：

> **生成图没有 ground truth。** 你不知道模型实际画了几辆车、画的是不是坦克、
> 阴影方向对不对、那片灰色到底是营房还是石头。
> 而我们要给它配的是「共 12 辆装甲车集结于开阔地，位于画面右上」这样的描述 ——
> **这句话的每一个字都是我们假设的，不是看出来的。**

这和本项目的第一条要求「宁可少，不许编」直接冲突。
生成图 + 生成描述 = 模型学会把幻觉说得理直气壮，这比数据少严重得多。

## 四、他们没提、但最该做的一条：**仿真引擎**

### 判断：**强烈推荐 —— 这是唯一能填「行为族」的方案**

回到开头那把尺子：**行为族全部需要「过程」**。

| 方案 | 能提供过程吗 | 标签可信吗 |
|---|---|---|
| 民用数据借调 | ❌ | 场景不是异常 |
| 开源遥感 | ❌ 单帧为主 | ✅ 但只有目标框 |
| AIGC 造内容 | ❌ | ❌ 全靠猜 |
| **仿真引擎** | ✅ **可脚本化任意过程** | ✅ **像素级精确** |

**关键差别**：仿真的标签不是标注出来的，也不是推断出来的，
而是**你亲手设定的** —— 你让 8 辆坦克从 A 点开到 B 点，那就是 8 辆，
坐标逐帧精确，队形、间距、速度全是已知量。

**能直接造出来的**（对应我们完全空白的行为族）：

| 行为 | 怎么造 |
|---|---|
| `massing` 集结 | 脚本化多路兵力向同一区域汇聚，导出时序帧 |
| `maneuver` 机动 | 车队沿路行进、装甲纵队转移 |
| `incursion` 越界 | 设定边界线，目标跨越，**边界位置是已知的** |
| `recon` 侦察 | 无人机盘旋航线、抵近观察 |
| `concealment` 伪装 | 同一目标的裸露态 vs 伪装网覆盖态，**天然成对** |
| `fortify` 工事构筑 | 同一地点的施工前/中/后序列，**天然成对** |
| `coordination` 协同 | 多实体同步脚本 |

可用的：**ARMA 3**（军事场景资产最全，有成熟的航拍脚本工具链）、
**Unreal Engine + Cesium**（真实地形 + 自定义模型）、
**AirSim / Isaac Sim**（无人机视角，自带精确标注导出）。

**代价说清楚**：仿真图像和真实航拍有**域差**（渲染感、纹理简化）。
所以不能只用仿真 —— 正确用法是
**真实数据打底（感知能力）+ 仿真补行为（判读能力）**，
并且在 golden set 里**只用真实数据评估**，否则测出来的是仿真上的成绩。

## 五、还有一条：**公开的军演影像**

各国军方、国防部官方渠道会发布大量演习影像（阅兵、演习、装备展示），
新闻机构也有航拍素材。这些是**真实的军事活动**，且公开可得。

- 优点：真实域、真实军事目标、真实行为
- 缺点：**没有标注**，要自己标；视角多为地面/低空，不全是航拍
- 建议：作为**评估集**和**少量高质量种子**，不指望它凑量

## 六、汇总：哪些采纳

| 方案 | 判断 | 填哪一格 |
|---|---|---|
| 民用数据 → 训感知能力 | ✅ **采纳** | 计数 / 定位 / 描述 / `concentration` |
| 民用数据 → 训异常判定 | ❌ **不采纳** | 已实测失败，会教模型见停车场就报警 |
| 民用数据 → 困难负样本 | ✅ **采纳（已做）** | `massing` 的负样本 |
| ADS-B / AIS 轨迹 | ⏸ **单独立项** | 非影像任务 |
| DOTA / SpaceNet | ✅ **采纳** | 目标识别；SpaceNet 多时相 → `infra_change` |
| 拼图造集结 | ❌ **不采纳** | 污染描述任务，模型学"找拼接缝" |
| MSTAR (SAR) | ⏸ **暂不** | 模态不符、粒度不符 |
| AIGC 域增强（布局不变） | ✅ **有限采纳** | 稀缺类的天气/光照变体，每张 ≤3 个 |
| AIGC 造内容 | ❌ **不采纳** | 没有 ground truth，与"宁可少不许编"冲突 |
| **仿真引擎** | ✅ **强烈推荐** | **唯一能填行为族的方案** |
| 公开军演影像 | ✅ **采纳** | 评估集 + 高质量种子 |

## 八、瓶颈到底是什么（2026-09-16，回答「是数据量对吧」）

### 不是 QA 条数，是**独立图数**

```
QA 条数 = 独立图数 × 每图出题数
```

右边两项只有**左边那个**代表真实信息量。扩问法只动右边。

| 类别 | 独立图数 | 凑到 25000 条需要每图出题 | 评价 |
|---|---|---|---|
| smoke | 12899 | **1.9** | ✅ 健康 |
| explosion | 8259 | **3.0** | ✅ 健康 |
| concentration | 7023 | **3.6** | ✅ 健康 |
| disaster | 1056 | **23.7** | ❌ 把同一张图讲 24 遍 |
| massing/personnel | 923 | **27.1** | ❌ 把同一张图讲 27 遍 |
| massing/equipment | 84 | **297.6** | ❌❌ 荒谬 |

**还有一笔更要命的账 —— 测试集**（按图分组切 8:1:1，测试集是 10% 的**图**）：

```
massing/equipment   测试集   8 张图   ← 这个评估结果没有统计意义
massing/personnel   测试集  92 张图   ← 同上
disaster            测试集 106 张图   ← 同上
```

**QA 条数再多也救不了这个** —— 8 张图上测出来的准确率，是噪声不是指标。

### 「扩充问法和回答池」—— 对，但要弄清它解决的是什么

这条建议**本身是对的**（也是硬性要求第 6 条），但它扩充的是
**语言多样性**，不是**视觉多样性**：

| | 防什么 | 靠什么扩 |
|---|---|---|
| 语言多样性 | 模型背问法模板、换个问法就不会 | **扩问法/回答池** ✅ |
| 视觉多样性 | 模型只认识这几百张图里的模式 | **只能靠更多图** |

对 VLM 来说，**后者才是主要瓶颈**。同一张图问 27 个不同问题，模型会把这张图背下来 ——
它学到的是「这张图的答案」，不是「这类现象长什么样」。

**经验区间：每图 3–8 道题。** 低于 3 浪费素材，高于 8 边际收益迅速递减，
超过 15 开始有害。

### 「多标签能扩充量」—— 部分对，要说清口径

多标签**不增加图**，它增加的是 `(图, 标签)` 配对数。

- ✅ **真实收益**：一张 explosion+smoke 的图，两个类都合法地算它一次 ——
  本来就该如此，不必去找两批不同的图。我们语料里这种共现有 **7819** 次
- ⚠️ **不是倍增器**：「每类条数」变好看了，但那是**统计口径变了**，
  视觉多样性一点没多。测试集还是那几张图

### 所以三级粒度：**要粗，不要细**

既然瓶颈是图数，**细分只会把同一批图切成更多更小的类**，每一格都不够训。

**建议的落地方式：**

```
二级（行为 8 + 征候 5）  → 作为**训练标签**，模型要学会判的就是这 13 类
三级（具体事件）          → 只写进 metadata，**不作为独立训练类别**
```

这样信息不丢（将来数据够了随时提升为训练类别），又不会现在就把样本切碎。

### 真正能移动指针的，只有三件事

按性价比排：

1. **多标签**（已定）—— 让现有图合法地服务多个类。**零成本，立即可做**
2. **新数据源** —— SpaceNet 多时相填 `infra_change`；公开军演影像
3. **仿真引擎** —— **唯一能填行为族**的方案，且标签精确

**扩问法是必须做的，但它不在这个列表里** —— 它提升的是每张图的利用效率，
天花板是 8 倍左右，而且到不了「视觉多样性」这一层。

### 一句话结论

> **smoke / explosion / concentration 三类，图数足够，可以放心做到 25000。**
> **massing / disaster 做不到，硬凑就是把同一张图讲二十几遍。**
> 这两类要么补数据源，要么诚实地降低目标条数 —— 按第一条要求，应该选后者。
