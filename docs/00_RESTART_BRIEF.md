## 一、一句话结论

**我们从「我想要这几类异常」出发，然后逼着现有数据去供给它们 —— 顺序反了。**

六个异常类，四个在验证中死掉，死因完全相同：**数据里没有这个现象**。

| 类 | 结局 | 死因 |
|---|---|---|
| 越界移动 `border_crossing` | 停用 | 单帧看不到运动，也没有"边界线"这个东西 |
| 灾害现场 `disaster` | 停用 | 规则成立，但没有数据源 |
| 车队机动 `convoy` | 停用 | 单帧几何分不出「车队」和「路边停车」（**量过，分布完全重叠**） |
| 异常聚集 `massing` | **正在死** | 只剩 1007 条，且语义混乱（见下） |
| 爆炸 `explosion` | ✅ 活着 | 8259，FASDD 的真标注迁移 |
| 烟雾 `smoke` | ✅ 活着 | 12899，同上 |

**活下来的两个有个共同点：它们是数据集自带的真标注，不是我们从几何里"推"出来的。**
死掉的四个也有共同点：**都是靠规则从 bbox 几何推断出来的高层语义。**

这就是教训的核心。

## 二、massing 现在的样子（为什么说它语义混乱）

```
massing/personnel  923 条  ← 全部来自 ERA 的标签：
                              parade 游行 / protest 抗议 / conflict 冲突
                              concert 演唱会 / party 聚会 / religious_activity 宗教活动
massing/equipment   84 条  ← Mendeley 的坦克簇
```

一场**演唱会**和一队**坦克集结**共用同一个标签「异常聚集」。这跟前面「飞机停车
算不算集结」是同一类错误，只是错在另一头 —— 那次是把正常当异常，这次是**把两类
完全不同的现象塞进一个标签**。

而且 `concert` / `party` / `religious_activity` 本身就不该算「军事异常」。

## 五、错在哪（方法论）

### 1. 先定类别，后找数据 —— 顺序反了

正确顺序是：**先看数据里真实存在什么，再定义能训的类别。**
我们反过来做了，于是四个类逐个在验证中死掉，每次都浪费一轮完整的
「实现 → 跑通 → 复查 → 发现是空的」。

### 2. 用几何规则推高层语义，注定不可靠

`共线 + 等距 + 细长 = 车队`？停车场的一排车完全一样。
`密度高 + 数量多 = 集结`？广场上的人流完全一样。
**实测量过：40 辆随机散车能凑出比真车队还整齐的"队列"（CV 0.077 vs 0.156）。**
分布完全重叠，不是阈值没调好，是这些量本身不含判别信息。

活下来的 smoke / explosion 恰恰不靠推断 —— 它们是标注里本来就有的。

### 3. 合成数据验证会骗人

`tests/convoy_fixture.py` 八个对照场景全部判对，真实数据上却 7/12 是误报。
合成数据只能验「逻辑对不对」，验不了「现实里分不分得开」。
**唯一有效的验证是让模型看真图。**

### 4. 我下结论太早，至少三次

- 说「DOTA 规则没跑通」→ 实际是按设计转困难负样本
- 说「车队能有几千」→ 实际几十条量级
- 说「密度修复解决了 massing」→ 复查发现 11/15 仍是误报

## 六、重来的话，建议这么走

### 第 0 步：先回答一个问题

**这个模型最终要在什么画面上、判什么？**

现有数据能支撑的，诚实地说只有这些：

| 能训的 | 依据 |
|---|---|
| **火 / 烟检测与描述** | FASDD 25097，真标注，实证可靠 |
| **航拍目标识别与计数** | VisDrone/DOTA/DroneCrowd/MAR20/Mendeley，框都是真的 |
| **军事目标识别**（坦克、军机、士兵） | Mendeley + MAR20 |
| **公共事件分类**（游行/抗议/灾害/体育） | ERA 的 25 类事件标签 |
| ~~军事异常活动检测~~ | **没有数据。** 集结、机动、部署，一个都没有 |

### 第 1 步：先跑自由看图，别先写规则

```bash
python tools/inspect_data.py --scenes data/all.jsonl --out-dir data/inspect --per-class 12
```
**看完真实图像再定类别。** 这一步早做能省掉后面四轮返工。

### 第 2 步：类别只从"数据自带的标注"里来

不要再用几何规则推高层语义。真要推，先按下面的方式验：

```
造两组对照数据 → 量判据在两组上的分布 → 分布重叠就放弃，别调阈值
```

### 第 3 步：每定一个类，立刻用自由看图复查

```bash
python tools/inspect_data.py --scenes data/all_ev.jsonl --out-dir data/recheck \
    --only-class <类名> --per-class 15
```
**模型说「没看到」就是没有。** 这个闭环比任何阈值调参都可靠。

## 七、如果坚持要做「军事异常检测」

那得补数据源，现有的九个供不出来。需要的是：

- **带运动的多帧素材** —— 集结、机动、部署都是过程，单帧拍不到
- **含真实军事活动的航拍** —— 而不是静态停放的装备

在拿到这类数据之前，现有语料能做的最诚实的产品是
**「航拍目标识别 + 火烟检测 + 公共事件分类」**，而不是「军事异常检测」。
