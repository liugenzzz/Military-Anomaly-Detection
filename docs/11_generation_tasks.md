# 生成任务清单：4 类异常 × 5 类任务 = 20 个生成任务（+ 正常 4 个）

> 这是 `build_vqa.py` 与 `llm_qa.py` 的实现规格。`docs/10` 定的是任务类型与配额，
> 本文把每一格具体化到「问什么、答什么、数据从哪来、谁来生成」。

## 总览

| 异常类 | 判定 | 定位 | 计数 | 描述 | 推理 | 小计 |
|---|---|---|---|---|---|---|
| 异常聚集 `massing` | 5,000 | 5,000 | 2,500 | 7,500 | 5,000 | **25,000** |
| 爆炸/火光 `explosion` | 5,000 | 5,000 | 2,500 | 7,500 | 5,000 | **25,000** |
| 烟雾 `smoke` | 5,000 | 5,000 | 2,500 | 7,500 | 5,000 | **25,000** |
| 越界移动 `border_crossing` | 5,000 | 5,000 | 2,500 | 7,500 | 5,000 | **25,000** |
| 正常 `normal` | 17,200 | 6,450 | 6,450 | 12,900 | — | **43,000** |
| **合计** | 37,200 | 26,450 | 20,450 | 42,900 | 20,000 | **143,000** |

**生成方式**：判定 / 定位 / 计数 = 规则（零成本、零幻觉）；描述 / 推理 = LLM（受 FACTS 约束）。
规则侧 84,100 条，LLM 侧 62,900 条。

**否定变体**：每个异常类的每类任务里，20% 是否定式提问（问一个该图不存在的异常），
答案必须是明确的「否 / 无 / 0」。这部分仍由规则生成。

## 一、异常聚集 `massing`（25,000）

数据来源：MAR20（军机）、Mendeley（tank）、DroneCrowd（人群）、ERA parade（人群，无 bbox）

### 1.1 判定 · 5,000 条 · 规则

```
Q: <image>画面中是否存在异常军事活动？
A: 是。画面中 9 个军用飞机目标在停机坪密集排列，符合装备集结特征。
```
```
Q: <image>作为值班分析员，判断这张图是否需要上报，并说明理由。
A: 需要上报。画面中约 34 名人员在开阔区域密集聚集，属于人员异常聚集。
```
- 答案由 `events[].type` + `subtype` + `evidence.count` 唯一决定
- 否定变体（20%）：`Q: 画面中是否出现烟雾？ A: 否，未观察到烟雾迹象。`

### 1.2 定位 · 5,000 条 · 规则

```
Q: <image>请标出画面中装备集结区域的位置，用 [x1,y1,x2,y2] 表示。
A: 装备集结区域位于 [312,168,704,395]。
```
- 坐标来自 `evidence.cluster_bbox`，归一化到 0–1000
- **人员聚集定位的是聚集区域整体，不是单个人头** —— DroneCrowd 是人头点标注，
  定位一个 16px 的人头没有训练意义
- 否定变体：`Q: 请标出越界目标的位置。 A: 画面中未发现越界移动目标。`

### 1.3 计数 · 2,500 条 · 规则

```
Q: <image>画面中可见多少架军用飞机？
A: 9 架。
```
- 答案来自 `objects_summary`，精确真值
- 否定变体：`Q: 画面中有几辆坦克？ A: 0 辆。`（用于含飞机不含坦克的图）

### 1.4 描述 · 7,500 条 · LLM

```
Q: <image>请描述这张航拍画面中的情况。
A: 这是一张卫星遥感画面，可见某机场停机坪区域。画面中上方停放 9 架军用飞机，
   呈两列规则排列，间距均匀，占据 [312,168,704,395] 区域。周边未见其他活动目标。
   该密集列队形态符合装备集结特征，建议持续观察。
```
- LLM 基于 FACTS 改写，禁止出现 FACTS 之外的内容
- **不得推测国别、番号、具体机型**

### 1.5 推理 · 5,000 条 · LLM

```
Q: <image>为什么判断画面中存在装备集结？请给出判定依据。
A: 判定依据有三点：一是目标类型为军用飞机，非民用航空器；二是数量达 9 架，
   超出常态停放规模；三是分布形态呈规则列队、间距均匀，符合集中部署特征。
   综合以上，判定为装备集结。
```
- **关键**：推理必须体现「军事目标 + 规模 + 分布形态」三要素，
  这正是与民用停车场/民航机场区分的依据

## 二、爆炸/火光 `explosion`（25,000）

数据来源：FASDD_UAV（火焰 bbox）、XD-Violence / UCF-Crime（真实爆炸，无 bbox）、ERA fire

⚠️ **两种语义要分开表述**：FASDD 是野火明火，XD/UCF 是爆燃。类别标签相同，答案用词不同。

### 2.1 判定 · 5,000 · 规则
```
Q: <image>画面中是否出现爆炸或火光？
A: 是。画面中部可见明显火焰，伴随烟雾扩散。            ← FASDD 来源
A: 是。画面中出现强烈爆燃闪光与碎片扩散。              ← XD/UCF 来源
```

### 2.2 定位 · 5,000 · 规则（**仅 FASDD 有 bbox**）
```
Q: <image>请标出火点位置。
A: 火点位于 [421,388,533,502]。
```

### 2.3 计数 · 2,500 · 规则
```
Q: <image>画面中可见几处火点？
A: 2 处。
```

### 2.4 描述 · 7,500 · LLM
```
A: 这是一张无人机航拍画面，画面中部偏右可见一处明火，火焰区域约在
   [421,388,533,502]，其上方伴随灰白色烟雾向东北方向扩散。周边为植被覆盖地表。
```

### 2.5 推理 · 5,000 · LLM
```
Q: <image>请说明判定为火光异常的视觉依据。
A: 依据为画面中存在高亮度橙红色区域，与周边地表形成强对比，且上方伴生烟雾柱，
   符合明火燃烧特征。无法从单帧判断起火原因。
```
- **最后一句是刻意的**：不确定的事要明说不确定，这是抗幻觉训练的一部分

## 三、烟雾 `smoke`（25,000）

数据来源：**仅 FASDD_UAV**（单点依赖）

### 3.1 判定 · 5,000 · 规则
```
Q: <image>画面中是否存在烟雾？
A: 是。画面左上方可见灰白色烟柱。
```

### 3.2 定位 · 5,000 · 规则
```
Q: <image>请框出烟雾区域。
A: 烟雾区域位于 [102,64,388,301]。
```

### 3.3 计数 · 2,500 · 规则
```
Q: <image>画面中有几处烟源？
A: 1 处。
```

### 3.4 描述 · 7,500 · LLM
```
A: 无人机航拍画面，左上方存在一处烟雾，呈灰白色柱状向上扩散，
   覆盖 [102,64,388,301] 区域，未见明火。地表为林地。
```

### 3.5 推理 · 5,000 · LLM
```
Q: <image>画面中的烟雾有什么特征？可能意味着什么？
A: 烟雾呈灰白色、柱状上升、边缘扩散，形态符合地面燃烧产生的烟羽。
   画面中未见明火，可能为初期燃烧或余烬阶段。军事语境下亦需考虑
   人工施放烟幕遮蔽的可能，但仅凭单帧无法区分。
```

## 四、越界移动 `border_crossing`（25,000）

数据来源：**仅 VisDrone-MOT**（单点依赖）+ 自动放置的虚拟边界

⚠️ **这一类是多帧任务**，输入是 3–4 帧序列，`images` 字段放多张

### 4.1 判定 · 5,000 · 规则
```
Q: <image><image><image>这三帧按时间顺序拍摄，判断是否有目标发生越界移动。
A: 是。共 3 个车辆目标由边界线南侧移动至北侧，构成越界。
```

### 4.2 定位 · 5,000 · 规则
```
Q: <image><image><image>请标出越界目标在最后一帧中的位置。
A: 越界目标位于 [214,388,266,436]、[402,371,455,419]、[578,392,631,441]。
```

### 4.3 计数 · 2,500 · 规则
```
Q: <image><image><image>共有几个目标越过了边界？
A: 3 个。
```

### 4.4 描述 · 7,500 · LLM
```
A: 三帧航拍序列，间隔约 1 秒。画面中 3 个车辆目标持续由南向北移动，
   在第二帧至第三帧之间越过禁区边界线，当前均位于禁区内侧。
```

### 4.5 推理 · 5,000 · LLM
```
Q: <image><image><image>请说明越界行为的发生方向与判定依据。
A: 判定依据为目标轨迹与边界线的相交关系：3 个车辆在首帧位于边界南侧，
   末帧位于北侧，运动方向持续向北，位移量超过画面对角线的 2%，
   排除静止抖动。方向为由界外进入禁区。
```

## 五、正常 `normal`（43,000）

数据来源：DOTA 民用聚集（困难负样本）、VisDrone-DET、Drone-Anomaly、ERA non-event、
异常视频的正常段（HIVAU/UCA 时间边界切出）

### 5.1 判定 · 17,200 · 规则
```
Q: <image>画面中是否存在异常军事活动？
A: 否。画面中 14 个车辆目标虽密集停放，但均为民用车辆，未见军事装备，
   属于正常停车场景。                                    ← 困难负样本，最重要
```
```
Q: <image>该画面是否需要上报？
A: 不需要。目标分布稀疏，未见集结、烟火或越界迹象。
```

### 5.2 定位（否定式）· 6,450 · 规则
```
Q: <image>请标出画面中的集结区域。
A: 画面中未发现符合集结特征的区域。
```

### 5.3 计数（否定式）· 6,450 · 规则
```
Q: <image>画面中有几辆坦克？
A: 0 辆。
```

### 5.4 描述 · 12,900 · LLM
```
A: 卫星遥感画面，可见一处停车场，内有 14 辆民用车辆规则停放。
   周边为建筑与道路。画面中未见军事装备、烟火或人员聚集，态势正常。
```
