# 质量筛选：构建之前先把脏数据挡在外面

一条脏样本的破坏力远大于一条好样本的贡献 —— 尤其是**标签错的样本**，它会直接教模型把正常场景认成异常。所以筛选必须在 QA 生成之前做，而不是生成完再回头补救。

筛选分**五道闸**，前四道纯规则（零成本、可复现），第五道用 VLM（有成本，只对通过前四道的样本做）。

---

## 闸 1：图像基础质量（`tools/screen.py`，规则）

| 检查项 | 默认阈值 | 为什么 |
|---|---|---|
| 文件可读 | — | 公开数据集损坏文件比想象中多，ERA/UCF-Crime 抽帧尤甚 |
| 最短边 | ≥ 224 px | 低于此值航拍小目标已不可辨认，标注再准也没用 |
| 宽高比 | 0.2 – 5.0 | 排除条带状裁切残片 |
| 模糊度（拉普拉斯方差） | ≥ 60 | 无人机运动模糊帧，抽帧时大量产生 |
| 亮度均值 | 15 – 240 | 排除全黑（夜间失效帧）与过曝 |
| 像素标准差 | ≥ 8 | 排除纯色图、纯云层、纯海面 |

模糊度阈值需要按数据源分别校准：卫星图本身锐利（阈值可提到 100），夜间监控帧天然偏糊（降到 30），一刀切会误杀。`--profile` 参数按 `source_dataset` 分别设阈值。

## 闸 2：标注合法性（规则）

- bbox 越界、宽高 ≤ 0、坐标反向 → 直接修正或丢弃
- bbox 最短边 < 4 px → 丢弃该框（不丢整图）；这类框对 grounding 训练是纯噪声
- 单图目标数 > 2000 → 标记可疑（DroneCrowd 的密集人头图会命中，需要单独走计数任务，不进 grounding）
- 类别不在本体词表内 → 记录并汇总，提示补 `LABEL_MAP` 映射
- **事件与标注自洽性**：声称 `massing` 但图里目标数 < 阈值 → 说明规则派生出了问题，丢弃

## 闸 3：跨数据集去重（dHash + 汉明距离）

这一条**必须做**，理由很实际：

- DOTA / FAIR1M / xView 都大量取自 Google Earth，**存在真实重叠**；不去重会导致同一张图既在 train 又在 test
- 抽帧产生的相邻帧几乎一样，不去重等于把一条样本复制几十份，训练集"看着大"但实际信息量没涨，还会让模型对该场景过拟合

做法：64 位 dHash，汉明距离 ≤ 5 视为近重复，同一簇只保留质量分最高的一张。跨数据集统一建索引，不要按数据集分别去重。

## 闸 4：视角一致性（规则 + 元数据）

你的目标是**航拍与监控视角**。但很多数据集混着地面平视照片：

- Kaggle 军机数据集 —— 大量是地面拍摄的展会/机场照片
- Roboflow 社区军事数据集 —— 网图爬取，视角混乱
- XD-Violence —— 相当部分来自电影，是电影镜头语言而非监控视角

处理：`Scene.view` 字段先按数据集打默认值，再由闸 5 的 VLM 逐张复核。**非航拍/监控视角的一律剔除**，不要试图"反正也是军事目标就留着"——视角不一致会让模型在真实航拍输入上失准。

## 闸 5：VLM 语义复核（有成本，只跑通过前四道的样本）

这是你的 LLM 产能真正该花在的地方。每张图问三个问题，用小模型（Qwen2.5-VL-7B 级别即可，不需要顶配）批量打分：

```
1. 视角判定：这张图是 航拍/卫星/地面监控/地面平视 中的哪一种？
2. 标签一致性：图中是否真的可以观察到「{声称的异常类型}」？(是/否/不确定)
3. 可用性评分：作为异常检测训练样本，这张图的质量评分 1-5 分，
   并说明扣分原因（模糊/遮挡/目标过小/场景无信息量/含无关水印字幕）
```

**保留规则**：视角符合 **且** 一致性为「是」**且** 评分 ≥ 3。

三个额外要求，都踩过坑：
- **必须允许模型答「不确定」**。不给这个选项，模型会强行二选一，筛选结果反而不如不筛。
- **「不确定」的样本不要直接丢**，单独存一个池子，人工抽检——这批往往是最难、最有训练价值的边界样本。
- **水印与字幕要单独检查**。UCF-Crime/XD-Violence 有大量带时间戳、台标、字幕的帧，模型很容易学会靠字幕猜类别（这是经典的捷径学习陷阱）。命中的做裁剪，裁不掉的丢弃。

## 建议的筛选强度

| 数据集 | 预期保留率 | 重点闸口 |
|---|---|---|
| ERA / CapERA | 85–90% | 闸 3 抽帧去重 |
| HIVAU-70k / UCA | 90%+ | 已是精标数据，主要做闸 1 |
| UCF-Crime / XD-Violence 抽帧 | **50–60%** | 闸 4 视角 + 闸 5 水印字幕，剔除率最高 |
| VisDrone / DOTA / FAIR1M | 90%+ | 闸 3 跨集去重 |
| FASDD_UAV | 80% | 闸 5 一致性（部分标签偏噪） |
| Mendeley UAV 军事目标 | 70–80% | 闸 5 剔除其中的合成增强图（视需要） |
| Kaggle 军机 / Roboflow 社区集 | **30–40%** | 闸 4 视角，绝大部分是地面平视 |

**整体预期保留率 65–75%**。如果你的保留率超过 90%，说明阈值定松了，回去收紧；低于 50% 说明误杀，检查是不是模糊度阈值没按数据源校准。

---

## 产出

`tools/screen.py` 输出三份文件：

- `scenes_kept.jsonl` —— 通过筛选的 Scene，直接进入 QA 生成
- `scenes_dropped.jsonl` —— 被剔除的，**带 `drop_reason` 字段**，不要直接删，用于回查阈值是否合理
- `screen_report.json` —— 各闸口剔除数、按数据集的保留率、近重复簇统计

**每次调阈值都重跑一遍报告再决定**，凭感觉调阈值是这一步最容易翻车的地方。
